# Project Instructions

## 1. Start the Backend (Laravel)
Open a terminal and run:
```bash
cd backend
php artisan serve
```
This will start the API server at `http://127.0.0.1:8000`.

## 2. Start the Frontend (React)
Open a **new** terminal and run:
```bash
cd frontend
npm run dev
```
This will start the user interface at `http://localhost:5173`.

## 3. Access the Admin Panel
1. Open your browser to **[http://localhost:5173/admin](http://localhost:5173/admin)**.
2. Enter the **Admin Key**:
   > **admin123**

## 4. Troubleshooting
- If the admin key doesn't work, ensure your backend server is running.
- If you see "Unauthorized", try re-entering `admin123`.
